# Verification Before Completion

Before claiming anything is done:

## Check
- [ ] Does the code/files actually exist? (list them)
- [ ] Does it work? (run it or show output)
- [ ] Was it committed? (git status, git log)
- [ ] Were side effects checked? (did it break anything else?)
- [ ] Is the ecosystem updated? (memory/, CLINE.md, changelog)

## Output
- Show the evidence, not just a summary
- If it's not verified, it's not done
