# Ecosystem Analyzer

## Macro Scanning
1. `du -sh` across all platform dirs — size anomalies
2. Compare agent/skill inventories across platforms — duplicates
3. Check git status across repos — uncommitted work

## Quantify Everything
- "827 MB" not "a lot"
- "12 duplicate agents" not "some overlap"
- "3 platforms have the same skill" not "there's redundancy"

## Recommendations by Effort
- **Immediate** (<5 min, safe)
- **Short-term** (<30 min)
- **Structural** (1-2 hours)

## Output
- Markdown report with tables
- Evidence for every claim
